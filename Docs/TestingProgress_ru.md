## 📝 Заметки

### Проблемы

1. **Интеграционные тесты с БД** — требуют наличия файла `compact.sqlite3` в правильной директории
2. **Статические синглтоны** — сложно тестировать, требуют рефакторинга для внедрения зависимостей
3. **Большое количество легаси кода** — требует постепенного покрытия тестами
4. **InventoryTests** — тест помечен как `[Fact(Skip = "Requires DI container setup")]` — требует настройки DI-контейнера

### Рекомендации по написанию тестов

1. **Именование**: `Method_Scenario_ExpectedResult`
2. **Структура**: Arrange-Act-Assert (AAA)
3. **Изоляция**: один тест — одна проверка
4. **Моки**: использовать Moq для внешних зависимостей
5. **Документация**: добавлять XML-комментарии к сложным тестам
