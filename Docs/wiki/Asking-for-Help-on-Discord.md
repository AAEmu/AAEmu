# Asking for Help on Discord

- Audience: Players, testers, and contributors
- Last verified against: `develop` on February 28, 2026
- Prerequisites: None

Channel: [AAEmu Discord](https://discord.gg/aaemu)

## Before posting

1. Read [Mini troubleshoot guide](Mini-troubleshoot-guide).
1. Search recent messages for the same error.
1. Collect minimum context from [Help Us Help You](Help-Us-Help-You).

## How to ask a good Discord question

Post one message that includes:

1. What you are trying to do.
1. What command or action you ran.
1. What happened instead (full error text).
1. Your environment:
   - OS and version
   - run mode (Aspire, manual, or Docker)
   - branch and commit if relevant
1. Steps you already tried.

## Suggested message template

```text
Goal: ...
Workflow: Aspire / Manual / Docker
Environment: OS ..., branch ..., commit ...
Steps: 1) ... 2) ... 3) ...
Expected: ...
Actual: ...
Error/log excerpt: ...
What I already tried: ...
```

## Discord etiquette that speeds up help

- Keep one issue per thread or message chain.
- Do not post screenshots of text logs when copy-paste is possible.
- Avoid `@` mentions unless explicitly requested.
- When solved, post what fixed it so others can benefit.
