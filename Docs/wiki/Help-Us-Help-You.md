# Help Us Help You

- Audience: Players, testers, and contributors
- Last verified against: `develop` on February 28, 2026
- Prerequisites: None

This page lists the minimum information needed for effective support.

## Minimum context checklist

Share these details when asking for help:

1. Workflow: Aspire, manual, or Docker.
1. OS and version.
1. Branch name and commit hash (if you built from source).
1. Exact command or action you ran.
1. Full error output (copy-paste text).
1. What you expected vs what actually happened.
1. What you already tried.

## Logs and artifacts

- Prefer text logs over screenshots.
- Include only relevant excerpts if logs are large.
- Redact secrets like passwords, tokens, and private hostnames.

## Reproduction quality

A good report should allow another person to reproduce the issue quickly.
Use numbered steps and keep them precise.

## Fast self-check before posting

1. Confirm required files exist (`compact.sqlite3`, `game_pak` path).
1. Confirm you are following the right guide for your workflow.
1. Confirm config values are in the expected file (`Config.Local.json` where
   applicable).
1. Confirm ports are not already in use.
