# Getting Help

- Audience: Players, testers, and contributors
- Last verified against: `develop` on February 28, 2026
- Prerequisites: None

## Where to ask for help

AAEmu support is available in two official community channels.
Use the one that best matches your need.

### Discord

Use Discord for fast back-and-forth troubleshooting and setup help.

- Invite: [AAEmu Discord](https://discord.gg/aaemu)
- Best for: real-time questions, quick checks, and active debugging
- Before posting: read [Help Us Help You](Help-Us-Help-You)

Detailed guide:
[Asking for Help on Discord](Asking-for-Help-on-Discord)

### GitHub Discussions

Use GitHub Discussions for longer-form, searchable support threads.

- Link: [AAEmu Discussions](https://github.com/AAEmu/AAEmu/discussions)
- Best for: design questions, implementation details, and solutions that should
  stay discoverable
- Before posting: read [Help Us Help You](Help-Us-Help-You)

Detailed guide:
[Asking for Help on GitHub Discussions](Asking-for-Help-on-GitHub-Discussions)

## Which channel should I choose

- Need quick help right now: use Discord.
- Want a durable answer others can find later: use GitHub Discussions.
- Unsure: start in Discord, then move final solution to Discussions if useful.
