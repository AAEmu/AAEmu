# Asking for Help on GitHub Discussions

- Audience: Players, testers, and contributors
- Last verified against: `develop` on February 28, 2026
- Prerequisites: None

Channel: [AAEmu Discussions](https://github.com/AAEmu/AAEmu/discussions)

## When to use Discussions

Use Discussions when your question and answer should stay searchable.
This is ideal for setup edge cases, architecture questions, and workflows.

## Before posting

1. Search existing discussions for your error or topic.
1. Read [Mini troubleshoot guide](Mini-troubleshoot-guide).
1. Gather context from [Help Us Help You](Help-Us-Help-You).

## How to structure your discussion

### Title

Use a descriptive title with key context.

Example:
`Aspire startup fails on Ubuntu 24.04 with missing MySQL connection`

### Body

Include these sections:

1. Goal and expected behavior.
1. Actual behavior and exact errors.
1. Environment details (OS, branch, commit, workflow).
1. Reproduction steps.
1. What you already tried.

- Workflow: Aspire / Manual / Docker
- Branch/commit:

## Follow-up

If you resolve the issue, edit or reply with the final fix.
That helps future users and reduces repeated support load.
